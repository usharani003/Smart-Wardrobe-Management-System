# Smart Wardrobe Management and Outfit Recommendation System

> MCA Final Year Project

A web-based wardrobe management system that allows users to
digitally organize clothing items and receive rule-based outfit
recommendations based on weather, occasion, color preferences,
and music mood.

## Features

- User registration and login
- Digital wardrobe management
- Clothing image upload
- Search and filtering
- Weather-based recommendations
- Occasion-based recommendations
- Color matching
- Music mood-based recommendations
- Admin dashboard
- User and fashion analytics
- System reports

## Technology Stack

| Technology | Usage |
|---|---|
| Java | Backend |
| JSP & Servlets | Web application |
| JDBC | Database connectivity |
| MySQL | Database |
| HTML, CSS, JavaScript | Frontend |
| Bootstrap | UI |
| Apache Tomcat | Server |

## Modules

### User Module
Registration, login, wardrobe management, image upload,
search/filter, and outfit recommendations.

### Recommendation Module
Weather, occasion, color matching, and music mood-based
recommendations.

### Admin Module
User analytics, fashion analytics, and system reports.

## Installation

1. Clone the repository.
2. Import the project into your Java IDE.
3. Create the MySQL database.
4. Import the provided SQL file.
5. Configure the JDBC connection.
6. Configure Apache Tomcat.
7. Run the project.
